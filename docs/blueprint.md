# **App Name**: TextQuest Adventures

## Core Features:

- AI Storytelling: Use a Large Language Model as a tool to interpret user input and advance the game's narrative.
- Text Display: Display the story text and player choices in a clear, readable format.
- Choice Selection: Allow the player to make choices to influence the direction of the story.

## Style Guidelines:

- Primary color: Dark gray (#333) for a serious, immersive feel.
- Secondary color: Light gray (#ddd) for text and UI elements.
- Accent: Teal (#4CAF50) for interactive elements and highlights.
- Clean, full-screen layout to draw the player into the game world.
- Subtle text animations to add dynamism to the story presentation.
